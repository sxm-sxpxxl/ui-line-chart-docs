TryValidate(out string)

Checks whether the selected data source can produce points; unlike GetData(), a failure is reported only through error and nothing is logged.

Declaration
public bool TryValidate(out string error)
Parameters
Type Name Description
string error

On failure, a message describing why; otherwise null.
Returns
Type Description
bool

true if the source can produce points; otherwise false.
Remarks

Call it after configuring a source from code and before adding the graph to a chart, to show the problem in your own UI. A Direct graph is always valid; a predefined source fails when:

  • a File source has no readable asset, or the asset does not match the selected format;
  • a Derived source has no source graph, derives from itself or through a chain that loops back, or its source is infinite or invalid itself;
  • a Curve source has no keys, or its Sample Size is below 1;
  • a finite Random or Waveform source has an X range that ends before it starts, or a Random source has such a Y range.
