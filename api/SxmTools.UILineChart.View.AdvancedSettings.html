    Scale

    Multiplies every chrome dimension — line and axis thicknesses, point sizes, offsets, dash widths and text size — while leaving the data untouched. The default 1 draws the chrome at the pixels you authored.

    Declaration
    [UxmlAttribute]
public float Scale { get; set; }
    Property Value
    Type Description
    float

    A positive multiplier; 1 is the authored size. Defaults to 1.
    Remarks

    This does not compensate for screen resolution: a panel that scales with screen size already scales the whole chart, meshes included. Reach for it when mirroring a chart as a smaller copy that must keep the original's visual weight (fold previewWidth / referenceWidth into the value); a chart authored for its own surface keeps 1 and sets thicknesses, sizes and text styles directly.
