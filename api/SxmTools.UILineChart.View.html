    AdvancedSettings

    Advanced chart settings: whether the chart initializes itself, and the chrome Scale multiplier.

    AxisSettings

    Axis settings: how values are distributed across the axes, how the labels are formatted and shown, and the two axis captions.

    DataSettings

    Data settings: the graphs and reference lines the chart shows, its points buffer, and how playback fills the graphs.

    GridSettings

    Grid appearance settings for the chart: how many columns and rows it draws behind the graphs, and how the axis lines look.

    LegendSettings

    Legend settings: whether the legend is shown, which side it sits on, how it aligns, its offset from the plot, and its header and entry text styles.

    LineChart

    Root UI Toolkit control that draws one or more graph series with a grid, axis labels, a legend and point tooltips. The single public entry point of the package: author it in UXML or UI Builder, or drive it from code after calling Init().

    PointTooltipSettings

    Point tooltip settings: the hover tooltip, the highlighted selection point, and the projection lines, points and labels dropped to each axis.
