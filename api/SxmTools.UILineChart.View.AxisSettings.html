    Class AxisSettings

    Axis settings: how values are distributed across the axes, how the labels are formatted and shown, and the two axis captions.

    Inheritance
    object
    AxisSettings
    Namespace: SxmTools.UILineChart.View
    Assembly: SxmTools.UILineChart.View.dll
    Syntax
    [UxmlObject]
public class AxisSettings
    Remarks

    A numeric setting outside its allowed range is rejected: the chart logs an error and the setting keeps its current value.
