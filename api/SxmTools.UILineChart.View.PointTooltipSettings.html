    Class PointTooltipSettings

    Point tooltip settings: the hover tooltip, the highlighted selection point, and the projection lines, points and labels dropped to each axis.

    Inheritance
    object
    PointTooltipSettings
    Namespace: SxmTools.UILineChart.View

    Syntax
    [UxmlObject]
public class PointTooltipSettings
    Remarks

    A numeric setting outside its allowed range is rejected: the chart logs an error and the setting keeps its current value.
