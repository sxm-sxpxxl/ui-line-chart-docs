# UI Line Chart — documentation

Read it at **[sxm-sxpxxl.github.io/ui-line-chart-docs](https://sxm-sxpxxl.github.io/ui-line-chart-docs/)**.

UI Line Chart is a line chart control for UI Toolkit in Unity 6. The site
covers getting started, a UXML-first and a code-first track, concept articles
and the API reference generated from the source.

This repository holds the generated site only, and nothing in it is edited by
hand. The sources live with the package, and `Documentation~/deploy.py`
rebuilds the site and pushes it here, replacing everything except `.git`,
`.gitattributes`, `.nojekyll`, this file, `LICENSE.md` and
`THIRD-PARTY-NOTICES.md`. Edits made here are lost on the next publish.
