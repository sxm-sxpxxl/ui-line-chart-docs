    Feed data at runtime

    Goal: a graph whose points come from your code while the application runs — a Direct graph — added to an initialized chart.

    Prerequisites: an initialized LineChart (Build a chart from code).

    Steps

    1. Create a GraphDescription with ScriptableObject.CreateInstance. A description is the chart's unit of data: one series plus its line and point styling. Give it a name — the legend shows it. Code is just the quickest way for this guide: a description saved as an asset (Assets ▸ Create ▸ UI Line Chart ▸ Graph Description, Mode = Direct) works the same. Reference it from code and continue at step 3, or list it in the chart's Data group in UI Builder and only push. Probe in the Overview sample is such an asset.
    2. Switch it to Direct mode: set Mode to DataSourceMode.Direct. A Direct graph has no predefined source; it draws whatever you push.
    3. Add it to the chart with AddGraph. The chart starts drawing the new series immediately.
    4. Push points with Push. Each call appends one Vector2 (x, y); the chart reveals it according to its playback settings.
    public static GraphDescription FeedDataAtRuntime(LineChart chart)
{
    var live = ScriptableObject.CreateInstance<GraphDescription>();
    live.Name = "Live";
    live.Mode = GraphDescription.DataSourceMode.Direct;
    chart.AddGraph(live);

    live.Push(new Vector2(0f, 0.5f));
    live.Push(new Vector2(1f, 0.8f));
    return live;
}

    Result

    The chart draws a second series named "Live" with two points. Keep calling Push from your update loop, a timer or a network callback and the line grows. RemovePushedPoint and ClearPushedPoints edit what is already there; RemoveGraph takes the series off the chart.

    A Direct graph remembers at most PushedPointsHistoryLimit points; how many the chart draws is a separate setting, the points buffer in the Data group.
