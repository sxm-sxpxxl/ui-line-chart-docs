    Getting started

    UI Line Chart is a line chart control for UI Toolkit in Unity 6. It draws one or more graph series over a grid, with axis labels, a legend and a hover tooltip, and it has exactly one public entry point: the LineChart control. Everything else — grid, axes, legend, datasets, playback — is configured on it.

    Install

    The package depends on com.sxm-tools.ui-factory, published on OpenUPM. Add the scoped registry and the package to Packages/manifest.json:

    {
  "scopedRegistries": [
    {
      "name": "package.openupm.com",
      "url": "https://package.openupm.com",
      "scopes": ["com.sxm-tools.ui-factory"]
    }
  ],
  "dependencies": {
    "com.sxm-tools.ui-line-chart": "https://github.com/sxm-sxpxxl/ui-line-chart.git"
  }
}

    Unity resolves both packages on the next domain reload. Optional: import the Overview sample from the Package Manager window — every guide uses it as the reference result.

    What you get out of the box

    Drop a LineChart into a UXML document (or create one from code) and it already draws: a default graph generated by a built-in GraphDescription asset, a grid, both axes with value labels, and a legend. In UI Builder the control renders a live design-time preview of whatever it is configured to show, so you see the chart while you edit it.

    The control is configured through six settings groups, each a child element in UXML and a property in code: Grid, Axis, Data, Legend, PointTooltip and Advanced. Every field in every group shows its documentation as a tooltip in the Inspector and UI Builder — the same text you read in the API reference.

    Pick your track

    You can work with the chart entirely without code, or entirely from code, or mix the two.

    • UXML-first — you author charts in UI Builder and describe data with GraphDescription assets. No C#. Start at Build a chart in UI Builder.
    • Code-first — you create the control in C#, configure the settings groups, and push data at runtime. Start at Build a chart from code.

    Both tracks meet in the Concepts: how datasets and data sources work, how playback fills a graph, what Scale is for, and how text styles are shared across charts.
