    Build a chart in UI Builder

    Goal: a chart authored entirely in UI Builder — grid and legend configured, live preview showing the default graph — with no C#.

    Prerequisites: the package is installed (Getting started) and a UXML document is open in UI Builder.

    Steps

    1. In the Library, find LineChart under the package's namespace and drag it into the hierarchy. The canvas shows the chart at once — the control renders a design-time preview in the editor.
    2. Select the chart. Its Inspector shows six foldouts, one per settings group. Open Grid (GridSettings) click the Columns Rows grid to pick 6 columns by 4 rows, and set Axis Stroke to Solid. The preview redraws as you type.
    3. Open Legend (LegendSettings) and set Side to Right.
    4. Hover any field to read what it does — every field carries the same documentation you find in the API reference.
    5. Save. UI Builder writes each configured group as a child element of the chart, with only the values that differ from the defaults.

    This is the UXML UI Builder produces:

    <ui:UXML xmlns:ui="UnityEngine.UIElements" editor-extension-mode="False">
    <SxmTools.UILineChart.View.LineChart name="line-chart" style="flex-grow: 1;">
        <SxmTools.UILineChart.View.GridSettings columns-rows="6,4" axis-stroke="Solid"/>
        <SxmTools.UILineChart.View.LegendSettings side="Right"/>
    </SxmTools.UILineChart.View.LineChart>
</ui:UXML>

    Result

    A chart with a 6×4 solid grid and the legend to the right of the plot, drawing the built-in default graph. In a runtime UIDocument it initializes itself on attach — nothing to call.
