    Add datasets

    Goal: the chart draws two graphs and one reference line, all described by assets you create in the Project window — still no C#.

    Prerequisites: a chart in UI Builder (Build a chart in UI Builder).

    Steps

    1. Choose Assets ▸ Create ▸ UI Line Chart ▸ Graph Description and name the asset. It is a GraphDescription: one series, its data source and its line/point styling.
    2. Select the asset. Under Data Source pick a predefined source — start with Waveform — and tune it; the Inspector explains each field and shows a formula card for the source. Create a second graph the same way.
    3. Assets ▸ Create ▸ UI Line Chart ▸ Reference Line Description makes a ReferenceLineDescription for a horizontal marker; set its Y Reference Value.
    4. Back in UI Builder, select the chart, open the Data group (DataSettings) and drag your two graph assets into Graphs and the reference line into Reference Lines. The preview draws them.
    5. Save. The Data group is written with project:// references to the assets:
    <ui:UXML xmlns:ui="UnityEngine.UIElements" editor-extension-mode="False">
    <SxmTools.UILineChart.View.LineChart name="line-chart" style="flex-grow: 1;">
        <SxmTools.UILineChart.View.DataSettings graphs="project://database/Packages/com.sxm-tools.ui-line-chart/Samples/Overview/Data/Measured.asset?fileID=11400000&amp;guid=18203195064ec91439b52ac2ca8f362e&amp;type=2#Measured,project://database/Packages/com.sxm-tools.ui-line-chart/Samples/Overview/Data/Forecast.asset?fileID=11400000&amp;guid=790794a5306e5624985b9cd57bba0309&amp;type=2#Forecast" reference-lines="project://database/Packages/com.sxm-tools.ui-line-chart/Samples/Overview/Data/Comfort.asset?fileID=11400000&amp;guid=79249e3d05fb2a2448ae2696dc13a2e3&amp;type=2#Comfort"/>
    </SxmTools.UILineChart.View.LineChart>
</ui:UXML>

    Result

    Two series and a horizontal reference line, each named in the legend. Change an asset later — a color, a frequency — and every chart that references it updates, in the editor preview and at runtime.
