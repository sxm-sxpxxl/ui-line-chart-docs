    Text styles

    What it is

    Every piece of text a chart draws — axis labels and captions, legend header and entries, the point tooltip and its projections, reference-line labels — is styled by key. The keys resolve against one project-wide asset, the TextStylesLibrary: a list of named TextStyleAttributes (font asset, size, color) plus a fallback style for unknown keys.

    How it works

    The library is a singleton resolved from Resources: the project's own TextStylesLibrary when there is one, otherwise the DefaultTextStylesLibrary the package ships. Charts do not own styles — they hold keys in their settings (XAxisLabelTextStyleKey, HeaderTextStyleKey, …), and every *TextStyleKey field in the Inspector is a dropdown over the library's keys. Change a style in the library and every chart using that key refreshes its text.

    Your project's library

    The package ships its styles as DefaultTextStylesLibrary, an asset inside the package that an installed package keeps read-only. A project overrides it with a TextStylesLibrary asset in any of its Resources folders. Tools ▸ UI Line Chart ▸ Open Text Styles Library opens that asset, or offers to create Assets/Resources/TextStylesLibrary.asset as a copy of the default when the project has none yet; the inspector of the default asset offers the same. The copy starts with the six keys every chart is authored against — AxisLabel, AxisCaption, LegendEntry, LegendHeader, ReferenceLineLabel, PointTooltip — so nothing changes until you edit a style or add a key of your own. Creating the copy reloads the scripts once, and from then on every chart resolves its keys against the project library.

    Resolution goes through TextStylesAttributes.Resolve: a known key returns its style; an unknown key logs an error and returns the FallbackStyle, so a typo never leaves text invisible.

    What it is not

    Text size is not a per-chart setting. Styles are shared, so a chart that needs bigger or smaller text points its *TextStyleKey fields at a different style rather than resizing anything on the chart itself. The one exception is a mirrored copy of another chart, where Scale shrinks or grows the text together with lines, points and offsets.

    Apply it

    Add a key to the library at runtime and point a chart's legend header at it:

    public static void PickATextStyle(LineChart chart)
{
    var library = TextStylesLibrary.Instance;
    var baseStyle = library.Styles.Entries[0].Style;

    library.Styles.Set("legend-large", new TextStyleAttributes(baseStyle.Font, baseStyle.FontSize + 4, baseStyle.Color));
    library.NotifyChanged();

    chart.Legend.HeaderTextStyleKey = "legend-large";
}
