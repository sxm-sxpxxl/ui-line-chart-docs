Playback

What it is

A chart does not necessarily show a dataset all at once. Its fill player reveals a graph's points over time — a finite source fills up and stops, an infinite or Direct one keeps flowing — according to the playback settings in the Data group.

How it works

The player ticks. Every tick it adds points to each playing graph:

Setting Meaning
Autoplay start filling on its own when the chart runs in play mode
UpdateMode Continuous — points appear tick by tick; Immediate — all at once
FillMode Fixed — PointsPerTick points each tick; Proportional — PercentPerTick of the data each tick
TickRate seconds between ticks — smaller is faster

From code you drive the same machinery per chart or per graph: Play, Stop, Restart (the int overloads take an index into Graphs), and IsPlaying to tell whether a graph is still filling. RevealFiniteImmediately shows every finite graph in full and skips the animation — it is what the chart does outside play mode so the editor preview is never empty.

Playback methods need an initialized chart; before Init() they throw.

What it is not

TickRate is a period, not a frequency: 0.05 means a tick every 50 ms, twenty ticks a second. And playback is not the same as the points buffer — the buffer caps how many points are kept, playback decides how fast they appear.

Apply it

Take manual control: turn autoplay off, choose a fixed fill of two points every 100 ms, then start:

public static void ControlPlayback(LineChart chart)
{
    chart.Data.Autoplay = false;
    chart.Data.UpdateMode = GraphUpdateMode.Continuous;
    chart.Data.FillMode = FillMode.Fixed;
    chart.Data.PointsPerTick = 2;
    chart.Data.TickRate = 0.1f;
    chart.Play();
}
