    Datasets and data sources

    What it is

    A chart draws descriptions: a GraphDescription is one series with its data and styling, a ReferenceLineDescription is one horizontal marker. Both are ScriptableObject assets, so the same description can sit on several charts and be edited in the Inspector; the chart's Data group lists which ones it shows.

    How it works

    A graph description is in one of two modes (DataSourceMode):

    Mode Where points come from Typical use
    Predefined one of six built-in sources, configured on the asset authored charts, previews, demos
    Direct Push calls from your code live data

    The predefined sources (PredefinedDataSource): Random — a random walk stepping along X; Manual — a hand-entered list of points; Curve — an AnimationCurve sampled into points; Waveform — a periodic wave (sine, square, triangle, sawtooth); File — points read from a JSON or CSV text asset; Derived — another graph transformed by an operation (moving average, change, total, derivative, integral). Derived graphs can chain: a derived graph may itself be the source of another.

    One property of a source matters beyond its shape: its Cardinality. A finite source produces a fixed number of points and stops; an infinite one keeps going from its X origin — Random and Waveform let you choose, and a Direct graph is infinite by nature. Playback treats the two differently, and the description reports the result as GraphDescription.Cardinality.

    When you edit a description, every chart showing it refreshes. Styling changes are applied in place. A change to the data itself — the mode, the source or one of its parameters — makes the chart reload that series; the chart tells the two apart by hashing the data settings, so only an edit that would change the produced points triggers a reload.

    What it is not

    A description stores the recipe for its points, not the points themselves. A predefined source generates them on demand from its parameters; a Direct graph keeps only a bounded history of what was pushed (PushedPointsHistoryLimit). How many points a chart draws is the chart's points buffer (PointsBufferLength, shared or per graph by PointsBufferMode), not a property of the description.

    Apply it

    Configure a predefined source from code exactly as the Inspector would:

    public static GraphDescription ConfigureAPredefinedSource()
{
    var graph = ScriptableObject.CreateInstance<GraphDescription>();
    graph.Name = "Wave";
    graph.SelectedDataSource = GraphDescription.PredefinedDataSource.Waveform;
    graph.WaveformData.Shape = GraphDescription.WaveShape.Sine;
    graph.WaveformData.Frequency = 2f;
    graph.WaveformData.Amplitude = 0.5f;
    return graph;
}
