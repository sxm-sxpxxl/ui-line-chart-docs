    Scale

    What it is

    Advanced.Scale multiplies every chrome dimension of a chart — line and axis thicknesses, point sizes, offsets, dash widths and text size — and leaves the data alone. The default, 1, draws the chrome at exactly the pixels you authored.

    How it works

    When the chart writes its descriptions and settings into its model, each pixel value is multiplied by Scale; change Scale later and the chart writes them again. Text follows the same rule: a text style's font size is multiplied before it is applied.

    Two situations look similar and are not:

    • Embedding — the chart is authored for the surface it appears on (a game HUD, an editor window). Thicknesses, sizes and offsets are per-chart settings, and every piece of text picks its style by key (see Text styles), so you set the values you want and Scale stays 1. It is not a shortcut for bigger text: a text style is the place for that, and Scale would drag lines, points and offsets along.
    • Mirroring — a chart is shown as a smaller copy of another chart and must look like the original. Equal pixels in a narrower box read as heavier lines, so the copy needs previewWidth / referenceWidth folded into Scale. This is the one case where a computed value belongs, and Scale is what makes it expressible. The Overview sample does exactly this: LineChartPreviewer copies the runtime chart into the Inspector and into a window and sets each copy's Scale from its own width against the panel's reference resolution (see ComputePreviewScale in Samples/Overview/Runtime/LineChartPreviewer.cs), with a hand-picked readability boost for the narrow Inspector column.

    What it is not

    Scale does not compensate for screen resolution. That is the panel's job: with a PanelSettings scale mode such as Scale With Screen Size, UI Toolkit scales the whole visual tree, generated meshes included, and a 2 px line authored against a 1920 reference becomes 4 physical pixels on a 3840 screen without anyone touching Scale. Nor does it change the plotted range — axes and data are untouched.

    Apply it

    The mirroring case — a preview that must keep the original's visual weight:

    public static void MirrorAChart(LineChart preview, float previewWidth, float referenceWidth)
{
    preview.Advanced.Scale = previewWidth / referenceWidth;
}
